One line, 140 characters, that gives the judge a quiet, earned moment of pride: a man who spent forty years signing with an X finally writes his own name — on his granddaughter's birthday card, slowly, in ink — and reads it aloud to her.

## Run it

```sh
python3 main.py
```

Writes the single line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). Deterministic, no network, no model calls.
